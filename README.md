# Carnet de tâches

To-do list pro dans un seul fichier HTML, sans serveur ni compte.

- Thèmes et sous-thèmes en couleur (création directe depuis une tâche)
- Tableau « Urgent » toujours en haut
- Thèmes en colonnes, réordonnancement manuel des tâches (glisser ou flèches ↑ ↓)
- Sous-tâches à cocher, échéances, attribution à une personne (pour info)
- Export / import en `.json` pour sauvegarder ou changer de navigateur

## Où sont mes données ?

Les tâches sont enregistrées **dans le navigateur** (localStorage) de la personne qui ouvre la page.
Rien n'est envoyé sur GitHub ni ailleurs : publier ce dépôt ne publie pas les tâches.
Pensez à exporter régulièrement depuis la colonne de gauche (Sauvegarde).

## Utilisation

Ouvrir `index.html` dans un navigateur, ou la version en ligne via GitHub Pages.
